# AstroBhakti mobile (Flutter)

Screens follow the Figma file page by page: onboarding, Home, routine and audio player, Explore and reader, Live darshan, Pooja booking (online, group, home), My Bhakti (mandir, notes, bookings, mantra count, privacy, accessibility, help).

## First run

The native `android/` and `ios/` folders are generated by Flutter:

```bash
cd mobile
flutter create . --org com.hernest --project-name astrobhakti --platforms android,ios
flutter pub get
flutter run --dart-define=API_BASE=http://10.0.2.2:8787/api
```

Start the backend first (`cd backend && npm start`). `10.0.2.2` is how the Android emulator reaches your computer; use your computer's LAN address on a real phone.

In development, **Pay** simulates the payment provider's webhook through `/api/dev/pay/:id`. In production the checkout route returned by the booking (store billing or gateway) confirms the booking via the signed webhook.

## Background audio

`just_audio` plays media. For lock-screen controls and background playback, add `audio_service` or `just_audio_background` and the Android foreground-service and iOS background-audio entries once the native folders exist.
